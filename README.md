# BlossomCalc

A modern glassmorphism calculator built with HTML, CSS, and JavaScript featuring dark mode, keyboard support, calculation history, and a clean pastel user interface.

## Live Demo

https://blossom-calc.vercel.app

## Features

- Basic arithmetic operations
- Calculation history
- Keyboard support
- Dark mode toggle
- Responsive design
- Glassmorphism interface

## Tech Stack

- HTML5
- CSS3
- JavaScript

Clone the repository:

```bash
git clone https://github.com/ShambhaviCode/BlossomCalc.git
```

Open `index.html` in your browser.
